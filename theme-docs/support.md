## What is covered

Theme support covers issues directly related to the Universe theme as purchased from the Shopify Theme Store:

- **Bug fixes** — If something in the theme is broken or behaves differently from what is described in this documentation, we will fix it.
- **Theme-related questions** — Questions about how to configure a setting, use a section, or achieve a result using the built-in theme options.
- **Compatibility issues** — If a Shopify platform update causes a theme feature to stop working correctly.

---

## What is not covered

The following are outside the scope of theme support:

- **Custom code modifications** — If you or a developer have edited the theme's code, we cannot guarantee support for issues that arise from those changes.
- **Third-party app integrations** — We do not provide support for configuring or troubleshooting Shopify apps. Contact the app developer directly.
- **Store setup and content** — Adding products, writing descriptions, setting up navigation menus, and configuring Shopify settings are outside the scope of theme support.
- **Custom design requests** — Requests to change the theme's layout, style, or functionality beyond what the Theme Editor allows are not covered.

For code customizations, we recommend hiring a verified [Shopify Partner](https://www.shopify.com/partners/directory). Please duplicate your theme before making any code changes.

---

## How to contact us

Submit a support request using the contact form linked from the Developpy website. Include the following information to help us respond faster:

- Your store URL (for example, `yourstore.myshopify.com`)
- A description of the issue
- The page or section where the issue occurs
- Screenshots or a screen recording if possible

---

## Response times

We respond to all support requests within **2 business days**. Critical issues that affect a live store's ability to function (broken checkout, broken product pages) are treated as urgent and addressed as quickly as possible.

---

## Before contacting support

Check these resources first — most questions are answered here:

- Browse the [section documentation](README.md) for the section you are working with
- Check the [FAQ](faq-general.md) for common questions
- Check the [Changelog](changelog.md) to see if a recent update addresses your issue
- Make sure you are using the latest version of the theme (check **Online Store > Themes** in your Shopify admin for update notices)
