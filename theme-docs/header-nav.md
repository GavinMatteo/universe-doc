# Header and Navigation
The Header and Navigation section controls the top bar of every page: logo, navigation menu, search, cart icon, and optional language and currency selectors. It supports four mega menu block types for rich dropdown navigation.
📌 **When to use it:** The Header is a global section active on every page. Configure it once in the Theme Editor.

## ⚙️ Section Settings

### Content and Layout

| Setting | What it does |
|---|---|
| **Logo selector** | Your store logo used in the header. For the transparent header state, upload a separate logo below. |
| **Logo size** | The display width of the logo on desktop, in pixels. |
| **Logo mobile size** | The display width of the logo on mobile, in pixels. |
| **Primary Menu** | The primary navigation menu. Menus are created in Shopify admin under Online Store > Navigation. |
| **Menu Layout** | The layout configuration of the header: controls the position of the logo, navigation, and utility icons. |
| **Secondary Menu** | A secondary navigation menu displayed in the header or mobile drawer. |
| **Enable transparent header in home page only** | When enabled, the header has a transparent background only on the home page. |
| **Enable Sticky header** | When enabled, the header stays fixed at the top as the visitor scrolls. |
| **Enable glass effect on scroll** | Adds a frosted glass effect to the header as the visitor scrolls down. |
| **Transparent header logo** | A separate logo used when the transparent header is active, typically a light-colored version. |
| **Transparent header text color** | The text and icon color when the transparent header is active. |
| **Blur radius** | The blur intensity of the glass effect on the sticky header background, in pixels. |
| **Cart Style** | Controls the appearance of the cart icon in the header. Choose between a bag or a cart icon style. |
| **Enable Search** | Shows a search icon in the header that opens a full search overlay when clicked. |
| **Search Color Scheme** | The color palette applied to the search overlay panel. |
| **Search Products Color Scheme** | The color palette for product cards shown in the predictive search results. |
| **Show Social Media (mobile)** | Shows social media icon links in the mobile navigation drawer. |
| **Show Language Selector** | Shows a language selector in the header. |
| **Show Currency Selector** | Shows a currency selector in the header. |
| **Enable Shop now button (desktop)** | Shows a Shop now CTA button in the desktop header. |
| **Shop now text** | The label on the Shop now button. |
| **Shop now link** | The URL the Shop now button links to. |


### Colors

| Setting | What it does |
|---|---|
| **Section's color palette** | Applies a color palette to this section, controlling the background, text, and button colors. Color palettes are defined in Theme Settings. |

## 🧩 Blocks

### Mega Menu - Shop

| Setting | What it does |
|---|---|
| **Menu item to apply to** | The exact label of the navigation menu item that triggers this mega menu. The match is case sensitive and must be identical to the nav item text. |
| **Submenu** | The navigation menu displayed as links inside this mega menu dropdown. |
| **Shop layout image** | An image displayed alongside the menu links in the mega menu, for example a campaign visual. |
| **Image url** | The URL the mega menu image links to when clicked. |


### Mega Menu - Collections

| Setting | What it does |
|---|---|
| **Menu item to apply to** | The exact label of the navigation menu item that triggers this mega menu. The match is case sensitive and must be identical to the nav item text. |
| **Collections** | The collections displayed as visual cards in the mega menu. |
| **CTA Text Collection Items** | A CTA link displayed below the collection cards, for example "View all collections". |


### Mega Menu - Products

| Setting | What it does |
|---|---|
| **Menu item to apply to** | The exact label of the navigation menu item that triggers this mega menu. The match is case sensitive and must be identical to the nav item text. |
| **Products** | The products displayed as visual cards in the mega menu. |
| **CTA Text Product Items** | A CTA text displayed below the product cards in the mega menu. |


### Mega Menu - Explore

| Setting | What it does |
|---|---|
| **Menu item to apply to** | The exact label of the navigation menu item that triggers this mega menu. The match is case sensitive and must be identical to the nav item text. |
| **Submenu** | The navigation menu displayed as links inside this mega menu dropdown. |

## 💡 Tips

- Use a sticky header so visitors always have access to navigation and the cart icon.
- If you use a transparent header on the home page, upload a separate logo for the transparent state.
- Test your navigation carefully on mobile.

## ❓ FAQ

**How do I enable a mega menu?**\
Add a Mega menu block and set the Menu item to apply to field to exactly match the navigation item label. The match is case sensitive.

**The transparent header text is hard to read.**\
Adjust the Transparent header text color setting to contrast with your hero image.

**The search bar is not showing.**\
Make sure the Enable search setting is turned on in the header settings.
