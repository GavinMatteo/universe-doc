## Install the theme

**From the Shopify Theme Store**

1. In your Shopify admin, go to **Online Store > Themes**.
2. Click **Visit Theme Store**.
3. Search for **Universe** and click **Try theme**.
4. The theme is added to your Theme library. You can preview it before publishing.

**From a zip file**

If you received the theme as a zip file:

1. In your Shopify admin, go to **Online Store > Themes**.
2. Click **Add theme**, then select **Upload zip file**.
3. Select your zip file and click **Upload**.
4. The theme appears in your Theme library.

To publish a theme and make it live, click the three-dot menu next to the theme name and select **Publish**.

## First steps after installation

After installing Universe, complete these steps before customizing:

1. **Add your logo** — Go to **Theme settings > Logo** and upload your store logo. Set the desktop and mobile size.
2. **Set up your navigation menus** — In Shopify admin under **Online Store > Navigation**, configure your main menu and footer menu. The theme references these automatically.
3. **Configure color schemes** — Go to **Theme settings > Colors** to define your palettes. Sections reference these palettes by name.
4. **Set typography** — Go to **Theme settings > Typography** to choose your fonts for headings, body text, and buttons.
5. **Add social media URLs** — Go to **Theme settings > Social media** and add your profile links. Icons appear automatically wherever social media icons are enabled.

## Understanding the Theme Editor

The Theme Editor is where you customize every aspect of the theme without touching code.

**How to open it**

In Shopify admin, go to **Online Store > Themes**, click the three-dot menu next to Universe, and select **Customize**.

**Layout of the editor**

- The **left sidebar** lists sections on the current page. Click any section to edit its settings.
- The **top bar** lets you switch between pages (home page, product page, collection page, and so on).
- The **bottom left** has a **Theme settings** button for global settings that affect the entire store.

**Sections vs Theme settings**

- **Sections** are content blocks on specific pages. Each section has its own settings.
- **Theme settings** are global options that apply everywhere: typography, colors, cart behavior, animations, and so on.

**Adding and reordering sections**

Click **Add section** at the bottom of the left sidebar to add a new section to the current page. Drag and drop sections to reorder them.

**Saving changes**

Click **Save** in the top right corner. Changes are not published until you save.

## Update the theme

When a new version of Universe is available:

1. In Shopify admin, go to **Online Store > Themes**.
2. You will see an **Update available** banner next to the theme.
3. Click **Update theme**. Shopify creates a duplicate of your current theme automatically before updating, so your existing settings and customizations are preserved.
4. Review the updated theme in the preview, then publish it when ready.

> Always review the [Changelog](changelog.md) before updating to understand what changed.

If you have made custom code changes to the theme files, back up your changes before updating. Code edits are not preserved automatically during a theme update.

---

## Before you edit the code

If you need to customize the theme beyond what the Theme Editor allows:

- Always **duplicate the theme** before editing any code. In your Theme library, click the three-dot menu and select **Duplicate**.
- Consider hiring a [Shopify Partner](https://www.shopify.com/partners/directory) for code-level work.
- Custom code changes are not covered by theme support. See the [Support](support.md) page for details.
