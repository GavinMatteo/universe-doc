# Drawer Cart
The Drawer Cart is a slide-in cart panel that appears when a visitor adds an item or clicks the cart icon. It lets visitors review their cart, apply discount codes, see a free shipping progress bar, and proceed to checkout without leaving the current page. It also supports cross-sell product suggestions.
**When to use it:** This section is active globally and appears on every page. Configure it once in the Theme Editor.

## Section Settings

### Content and Layout

| Setting | What it does |
|---|---|
| **Enable Free Shipping Bar** | Shows a progress bar indicating how close the visitor is to the free shipping threshold. |
| **Enable** | Shows a product suggestion row in the cart drawer to encourage additional purchases. |
| **Heading (mobile)** | The heading shown above the cross-sell products on mobile. |
| **Scrolling text (Desktop)** | A scrolling text label shown above the cross-sell products on desktop. |
| **Products** | The products to suggest in the cross-sell area. Select them from your catalog. |
| **Show conversion boost copy** | Shows a short reassurance line with an icon above the checkout button. |
| **Copy text** | The text of the reassurance line, for example "Free returns on all orders". |
| **Icon** | The icon shown next to the conversion copy line. |
| **Show cart notes** | Shows a text area where visitors can leave an order note. |
| **Show discount code input** | Shows a field for entering a discount code in the cart. |
| **Show view cart button** | Shows a secondary button linking to the full /cart page. |
| **Show checkout button** | Shows the main Checkout button. |
| **Show payment icons** | Shows accepted payment method icons below the checkout button. |
| **Show terms and conditions** | Shows a checkbox visitors must accept before proceeding to checkout. |
| **Cart style** | The visual style of the cart items (rounded or square corners). |
| **Message** | The message shown when the cart is empty. |
| **Button 1 text** | The label for the first button on the empty cart screen. |
| **Button 1 link** | The URL the first empty cart button links to. |
| **Button 2 text** | The label for the second button on the empty cart screen. |
| **Button 2 link** | The URL the second empty cart button links to. |
| **Button 3 text** | The label for the third button on the empty cart screen. |
| **Button 3 link** | The URL the third empty cart button links to. |
| **Summary color scheme** | The color palette for the cart summary footer (subtotal and checkout button). |
| **Use custom colors** | Overrides the color scheme with manually set custom colors. |
| **Background color** | A custom background color, used when Use custom colors is enabled. |
| **Text color** | The color of text inside this section or block. |
| **Cards background** | Custom background color for cart item cards. |
| **Upsell column background** | Custom background color for the cross-sell product area. |
| **Upsell cards background** | Custom background color for cross-sell product cards. |
| **Upsell button background** | Custom background color for the add button on cross-sell cards. |
| **Upsell text color** | Custom text color for the cross-sell product area. |


### Colors

| Setting | What it does |

## Tips

- Enable the free shipping bar if you have a free shipping threshold. It is one of the highest-impact cart incentives.
- The cross-sell product list is manually configured and shows the same products to all visitors.

## FAQ

**The Drawer Cart is not appearing. Why?**\
Make sure Cart type is set to Drawer in Theme Settings > Cart.

**The free shipping threshold does not match my settings.**\
The threshold here overrides the global one in Theme Settings > Cart. Make sure both match.
