# 📐 General settings

Some settings appear in almost every section of Universe. This page explains them once so you do not need to re-read them for every section.

**On this page**

- [Color scheme](#color-scheme)
- [Padding](#padding)
- [Highlighted text](#highlighted-text)
- [Shape Divider block](#shape-divider-block)

---

## Color scheme

Every section has a **Section's color palette** setting in the Colors group. Use it to assign one of the color palettes defined in **Theme settings > Colors** to that section.

This controls the background color, text color, button color, and link color of the entire section. Changing the palette on one section does not affect other sections.

**Use gradient as background** — when enabled, the section uses the gradient defined in the selected palette instead of a solid background. Gradients are configured per palette in Theme settings > Colors.

---

## Padding

Every section has four spacing settings:

| Setting | What it does |
|---|---|
| **Padding top** | Space above the section content on desktop, in pixels. |
| **Padding bottom** | Space below the section content on desktop, in pixels. |
| **Padding top (mobile)** | Space above the section on mobile. Set independently from desktop. |
| **Padding bottom (mobile)** | Space below the section on mobile. Set independently from desktop. |

Use padding to control how tight or airy sections feel relative to each other. A value of 0 removes all space. Typical values range from 40 to 120 pixels.

## Highlighted text

Several sections include a **Highlighted text** setting on the heading. This adds an animated visual effect to selected words.

**How to apply it**

1. Type your heading in the editor.
2. Select the word or words you want to highlight.
3. Click the **Italic** button (I) in the text editor toolbar.
4. The highlighted style is applied to the italic text.

**Highlighted text style** — controls the animation type: Underline, Scribble underline, Text color, Thick underline, Outline, or Background color.

**Highlighted text color** — the color of the highlight effect.

> Note: Highlighted text applies only to certain section and block headings, not to body text or paragraphs.

## Shape Divider block

The Shape Divider is an optional block available in most sections. It adds a decorative SVG shape at the top or bottom edge of the section to create a smooth visual transition into the next section.

| Setting | What it does |
|---|---|
| **Choose position** | Top or Bottom. Controls which edge of the section the divider appears on. |
| **Section's color palette** | The color palette of the divider shape. Match it to the section it belongs to. |
| **Next section's background color** | The exact background color of the section below this one. Set it correctly to make the divider edge blend seamlessly. |
| **Style** | The shape style: Waves, Deep waves, Arc, Big curve, Oblique line, Triangle, or shaded pattern variants. |

**How to use it correctly**

The Shape Divider works by drawing a shape that appears to connect two sections. For the illusion to work, the **Next section's background color** must exactly match the background color of the section below. If it does not match, there will be a visible gap or color mismatch at the edge.
